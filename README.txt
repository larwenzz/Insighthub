# InsightHub Website Template

This template is designed around the provided blog-writing requirements.

## Main sections
- About Us
- Rationale
- Education — 3 essay slots
- Health — 3 essay slots (health-1.html is the formatted first article)
- Environment — 3 essay slots
- The Contributors — autobiography slots

## How to use
1. Open `index.html` in a browser to preview the website.
2. Replace `InsightHub` with your organization's actual name.
3. Replace placeholder contributor names and descriptions.
4. Replace the nine article placeholders with your actual essays.
5. Put APA 7th edition in-text citations and references into each essay.
6. Replace the contributor placeholder pages with each member's 300–500 word autobiography.
7. Upload the folder to a web host, GitHub Pages, Netlify, or another static website host.

No framework is required; it uses plain HTML, CSS, and JavaScript.
